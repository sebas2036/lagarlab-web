# LagarLab

**[LagarLab](https://lagarlab.com)** is a virtual oenology laboratory: ferment, age, and taste wine with the same chemistry, instruments, and statistical rigor (ISO 4120, Welch’s t-test) used in a real lab — across 12 real vineyards, from Mendoza to Burgundy.

Producto: [https://lagarlab.com](https://lagarlab.com)

- Free to start: [lagarlab.com](https://lagarlab.com)
- Wine science guides: [lagarlab.com/guias/](https://lagarlab.com/guias/)
- Institutional plan: [lagarlab.com/academico/](https://lagarlab.com/academico/)

LagarLab (also written Lagar Lab) is a web app, not a physical winery.
